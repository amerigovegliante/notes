## Computability

- **Effective Procedure (or algorithm)**: A sequence of elementary steps that solve a problem being executed on some idealized machine. 
\
INPUT --> [BLACK BOX] --> OUTPUT
\
If it's deterministic --> Function $f: \{inputs\} --> \{outputs\}$

- **Computable function**: A function $f$ is computable if there is some effective procedure that the function induced by the algorithm is $f$.

- **Existence of non-computable functions**:
    - **Characteristics of a "good" algorithm**: 
        - Finite length
        - There is a computing agent which executes the algorithm
            - Memory (unbounded)
            - Discrete steps, deterministic, not probabilistic
            - Instruction set that has a finite limit to the number and power
            - The computatio can
                - Terminate after a finite set of steps ==> Output
                - Diverge ==> No output

    We restrict to unary partial functions over naturals $f: N --> N$

    $F = \{f | f : N --> N\}$ set of all functions.

    Fix  a model of computation --> Set algoritms $A$ and given A $in A$ and $fA: N --> N$ functions computed by A.

    Set of computable functions in A: $FA = \{f in I | there is a in A s.t. f=fA\} = \{fA | A in A\}$
